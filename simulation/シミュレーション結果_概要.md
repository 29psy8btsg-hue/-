# 就労継続支援B型（愛媛県西条市）開設シミュレーション　結果の概要

前提：定員20名・人員配置6:1・2027年4月開設・初期投資900万円。人件費や家賃は仮の値。
詳しい前提と計算式は `B型_愛媛_開設シミュレーション.xlsx` にまとめています。

## わかったこと

1. **採算の分かれ目は1日の利用者数「12人」あたり。** 10人前後だと、報酬区分が低いままでは赤字になります（感度分析シート）。
2. **放デイ卒業生の受け皿が集客の土台になる。** 開設初月から5人以上を確保できるかどうかで、黒字化の時期が大きく変わります。日吉・西条の中高生の卒業予定を早めに把握することが大切です。
3. **平均工賃1.8万円が一つ目の壁。** 令和8年6月の見直しで区分の基準額が3,000円上がったため、1.8万円を超えないと報酬区分が上がりません。作業の開拓（農福連携、ラトリエトゥボナペティとの連携など）が収益に直結します。
4. **運転資金を約1,400万円見込んでおく必要がある。** 国保連からの入金は2か月遅れのため、初期投資900万円に加えて立ち上げ期の資金が必要です。

## 要確認事項

- 西条市・今治市でB型が総量規制の対象になっていないか（障害福祉計画の見込量）
- 地域区分（1単位10円と仮定）と、新規指定事業所の初年度の算定区分
- 令和9年度報酬改定（2027年度）の内容
- 実際の家賃、給与水準、サービス管理責任者を確保できるか
