# 議事録テンプレート

Excel版とWord版の2種類を置いています。どちらも中身の項目は同じです。

| ファイル | 形式 | 向いている使い方 |
|---|---|---|
| `議事録テンプレート.xlsx` | Excel | ToDoの期限や担当を**あとから追いかけたい**とき |
| `議事録テンプレート.docx` | Word | 決まったことを**文章で残して配布したい**とき |

## どちらを使うか

**迷ったらExcel版をおすすめします。** 議事録でいちばん価値があるのは「誰が・何を・いつまでに」で、
Excelならそれを全会議ぶん1か所に集めて、期限切れを自動で赤く表示できます。
Wordだとその一覧が作れず、ファイルを1つずつ開いて確認することになります。

Word版が向くのは次のような場合です。

- 議論の経緯や背景を**長い文章で**残す必要がある（役員会、監査対応、契約まわりなど）
- 社内に決まった議事録フォーマットがあり、体裁をそろえる必要がある
- 印刷・PDF配布が前提で、見た目の整えやすさを優先したい

両方を併用するのも現実的です。議事録本体はWordで書き、ToDoだけExcel版の
「アクション管理」シートに集める、という使い分けができます。

## Excel版の構成

| シート | 内容 |
|---|---|
| 使い方 | 色の凡例、進め方、ToDoの進捗サマリー（自動集計） |
| 議事録 | 1回分の議事録。会議ごとにシートをコピーして使う |
| アクション管理 | 全会議のToDoを集約。期限切れは赤、3日前は黄色に自動着色 |
| 会議ログ | 開催した会議の一覧。ToDo件数・未完了件数を自動集計 |
| 設定 | ステータス（未着手／対応中／完了／保留／中止）の選択肢 |

- **うすい黄色**のセルが入力欄、**グレー**のセルは数式なので触らないでください。
- **うすい緑**の行は記入例です。使い始めるときに行ごと削除してください。

## Word版の構成

会議の目的 → アジェンダ → 決定事項 → アクションアイテム → 議事内容 →
保留事項 → 次回予定 → 添付資料、の順に並んでいます。
最終ページに使い方のメモがあるので、配布前にそのページごと削除してください。
グレーの斜体はすべて記入のヒントです。

## ファイルの作り直し

`_generate_xlsx.py` / `_generate_docx.py` が、この2ファイルを生成したスクリプトです。
項目を足したり社名を入れたりしたい場合はスクリプトを編集して再生成できます。

```bash
pip install openpyxl python-docx
python3 _generate_xlsx.py 議事録テンプレート.xlsx
python3 _generate_docx.py 議事録テンプレート.docx
```

Excel版を作り直したときは、数式のキャッシュ値を入れるため LibreOffice で一度
開いて保存し直すか、再計算を挟んでください。
